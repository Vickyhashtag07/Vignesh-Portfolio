# Vigneshkumar M Portfolio

Professional portfolio website with:

- Home page
- English / Japanese language switch
- Separate Resume page
- Separate Work History page
- Direct PDF downloads
- Responsive premium dark design

## Open locally

Extract the zip and open `index.html`.

## GitHub upload

1. Create a new repository named `portfolio`
2. Upload all files and folders
3. Enable GitHub Pages from Settings → Pages
4. Select branch: `main` and root folder

## Important files

- `index.html` — main portfolio
- `resume.html` — resume page
- `work-history.html` — work history page
- `docs/Vigneshkumar-Resume.pdf` — resume PDF
- `docs/Vigneshkumar-Work-History.pdf` — work history PDF
